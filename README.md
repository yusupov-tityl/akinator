Квиз «Загадайте задачу — джинн угадает ИИ-агента» для стенда Ай-Титул на CNews FORUM 2026.

Открыть: https://genie.itityl.ru (на планшетах стенда — https://genie.itityl.ru/?kiosk=1)

Как работает:
- джинн задаёт вопросы о проблемах в работе: симптомы, причины, контекст, системы;
- после каждого ответа пересчитывает вероятность для каждого из 48 агентов и выбирает следующий вопрос, который лучше всего разделяет кандидатов;
- в конце показывает подобранных агентов, оценку эффекта и рыночные аналоги.

Это одна HTML-страница: данные, картинки и скрипты встроены. Ответы посетителей никуда не отправляются.
